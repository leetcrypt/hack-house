hack-house · commands

Everything listed here works from this browser. hack-house's other slash commands belong to the native TUI and are deliberately not reachable from a share link, so they are not listed — typing one here just posts it to the room as chat.

chat commands — tap to load into the chat box

Anything else you type in the chat box is sent to the room as an ordinary message. Asking the agent a question is just chat, but /ai !… and /ai confirm make it act in the sandbox, so they need the same drive approval as typing does — without it they are refused rather than posted.

quick shell actions — tap to load into the command bar

These need drive. The command bar and quick-keys under the terminal send keystrokes reliably from any phone keyboard — that is what makes clear and shell commands work on mobile, where the raw terminal often can't capture typing.

buttons, not commands

The room owner must run /grant web-publisher in the native TUI before your keystrokes reach the shell — that's the drive ACL, and the web deliberately can't bypass it.
